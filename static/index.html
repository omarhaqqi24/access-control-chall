Secure File Manager

AppArmor / Access Control

SOAL UAP ACCESS CONTROL

Sebuah perusahaan IT mengembangkan aplikasi bernama File Manager yang digunakan untuk mengelola dokumen dan file sementara milik pengguna.

Aplikasi tersebut berjalan menggunakan executable /usr/local/bin/file-manager. Untuk menjaga keamanan sistem, administrator ingin menerapkan pembatasan akses menggunakan AppArmor.

Administrator menetapkan beberapa kebijakan berikut:

  1. Aplikasi hanya diperbolehkan membaca file konfigurasi yang berada di direktori /etc/file-manager/.
  2. Aplikasi diperbolehkan membaca dan menulis file yang berada di direktori /tmp/file-manager/ untuk kebutuhan penyimpanan sementara.
  3. Aplikasi diperbolehkan membaca file yang berada di direktori /home/ untuk mengakses dokumen pengguna.
  4. Aplikasi tidak diperbolehkan melakukan operasi penulisan (write) terhadap file apa pun yang berada di direktori /var/log/.

Administrator meminta kamu membuat profil AppArmor yang menerapkan seluruh kebijakan tersebut.

Berdasarkan skenario di atas, buatlah sebuah profil AppArmor untuk aplikasi /usr/local/bin/file-manager dengan memenuhi seluruh ketentuan akses yang telah ditetapkan administrator.

Ketentuan pengerjaan

  1. Gunakan struktur profil AppArmor yang benar.
  2. Gunakan #include <tunables/global> dan #include <abstractions/base>.
  3. Tentukan permission untuk setiap direktori sesuai kebutuhan aplikasi.
  4. Gunakan aturan deny untuk membatasi operasi penulisan pada direktori log.
  5. Pastikan profil dapat dimuat oleh AppArmor tanpa kesalahan sintaks.

Submit konfigurasi profil AppArmor melalui website CTF yang disediakan.

Profil AppArmor MAKS. 20 KB

Tulis atau tempel seluruh profil. Pemeriksaan sintaks tidak memuat profil ke kernel.
